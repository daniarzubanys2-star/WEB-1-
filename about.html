The part I started from: AMD Ryzen 5 7600X

Every build starts with one decision, and for me it was the processor. I chose the Ryzen 5 7600X because it gives six modern cores for a price a student can survive, and because it uses the AM5 socket, so the motherboard will accept newer processors later. It is hot under load, so a good cooler is not optional here. After two months of daily use I still think it was the right choice for a machine that has to compile code in the morning and run games at night.

Key dates of the Ryzen family

  1. March 2017 — the first Ryzen processors arrive on the AM4 socket.
  2. July 2019 — Zen 2 brings PCIe 4.0 to consumer desktops.
  3. November 2020 — Zen 3 changes the internal core layout.
  4. September 2022 — Ryzen 7000 and the new AM5 socket are released.
  5. January 2023 — cheaper non-X models of the same generation appear.
  6. August 2024 — Zen 5 continues on the same AM5 socket.

Facts about my processor

  • 6 cores and 12 threads, which is enough for study and for games.
  • Boost clock up to 5.3 GHz on a single core.
  • Rated at 105 W, so it needs a tower cooler, not the small box one.
  • Works only with DDR5 memory — DDR4 modules do not fit AM5.
  • Supports PCIe 5.0 for the video card and for fast SSD drives.

Install the cooler before you close the case, not after.
